# Print mrf3 summary

Print mrf3 summary

## Usage

``` r
# S3 method for class 'summary.mrf3_fit'
print(x, digits = 3, max_shared_frac_rows = 8L, ...)
```

## Arguments

- x:

  Summary object from
  [`summary.mrf3_fit()`](https://novawz.github.io/multiRF/reference/summary.mrf3_fit.md).

- digits:

  Digits used for numeric formatting.

- max_shared_frac_rows:

  Maximum number of shared-fraction rows to print.

- ...:

  Additional arguments (unused).

## Value

The input object, invisibly.
