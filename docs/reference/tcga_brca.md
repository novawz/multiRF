# TCGA BRCA Expression Data

A dataset containing matched mRNA, miRNA, and DNA methylation features
from the TCGA BRCA cohort.

## Format

A named list with three data frames:

- gene:

  mRNA expression features.

- methy:

  DNA methylation features.

- mirna:

  miRNA expression features.

## Source

<https://www.cancer.gov/tcga>
