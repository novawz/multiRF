# Print method for `mrf3` objects

Displays a compact summary of fitted multiRF models including block
names, connection structure, weight statistics, and class info.

## Usage

``` r
# S3 method for class 'mrf3'
print(x, max_weights = 5L, ...)
```

## Arguments

- x:

  An `mrf3` object.

- max_weights:

  Maximum number of top variables to display per block.

- ...:

  Additional arguments (unused).

## Value

The input object, invisibly.
